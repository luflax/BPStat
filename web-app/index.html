Tax Data Configuration Guide

How to Configure Tax Series

Follow these steps to enable tax data visualization:

Step 1: Find Series IDs

  1. Visit https://bpstat.bportugal.pt/
  2. Search for: "receitas fiscais", "IRS", "IRC", or "IVA"
  3. Click on a relevant series
  4. Copy the series ID from the URL: https://bpstat.bportugal.pt/serie/[ID]

Step 2: Configure in app.js

Open app.js and find the TAX_CONFIG object. Add your series IDs:

const TAX_CONFIG = {
    enabled: true,
    series: {
        total: { id: '123456', label: 'Total Tax Revenue' },
        irs: { id: '234567', label: 'IRS' },
        irc: { id: '345678', label: 'IRC' },
        iva: { id: '456789', label: 'IVA' }
    }
};

Step 3: Test

Reload the page and click "Load Tax Data"
